# Enhanced Clipboard 0.4.0

This release replaces the clipboard pipeline with a single-writer engine and a
single authoritative frontend view. Images are now stored only after their
original and preview files are fully ready, and clipboard UI updates use one
best-effort invalidation event.

## Upgrade notice

The first 0.4.0 launch rebuilds `clipboard.db` as schema v9. This intentionally
clears all clipboard history, including pinned entries. `settings.db`, saved
application settings, and persisted UI/window state are preserved.

In-flight image capture may be lost if the application exits, and background
captures may be dropped when the bounded engine mailbox is full. These are
intentional tradeoffs documented in ADR 0001.
